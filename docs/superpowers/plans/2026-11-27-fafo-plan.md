# FAFO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build FAFO, a read-only observer of Claude, Codex, Gemini, Copilot cloud, Ollama and CI runners that never blanks under load, with a TUI and a Claude Code pane.

**Architecture:** A collector runs one worker per source (own interval, hard timeout, backoff). Workers return typed rows, the redactor scrubs them, and the store writes one timestamped snapshot file (0600, atomic rename). Renderers (table/JSON, Textual TUI, Claude Code pane) only read the snapshot. SAFO and SHIT are optional adapters that enrich sessions.

**Tech Stack:** Python 3.11+, psutil, Textual, httpx, pytest; TypeScript/TSX for the Claude Code pane mod. All dependencies pinned.

**Spec:** `docs/superpowers/specs/2026-11-27-fafo-design.md`. Epic: the FAFO epic. Task issues are filed per task below and move to the FAFO repo once it exists.

## Global Constraints

- Public repo, personal account (owner confirms at creation); read-only tool, no kill/dispatch/merge.
- American English, no em dashes anywhere (code output included); dark theme only.
- Redact before write: argv allowlist-first, env never collected, transcript text never stored, hostnames/IPs mapped to configured aliases.
- Snapshot and socket mode 0600, owner only.
- GitHub data via REST only, ETag conditional requests, configured poll floor; never GraphQL board listing; GitHub App token, Actions read only.
- Remote hosts agentless over read-only ssh, `BatchMode=yes`, `ConnectTimeout`, pinned key via `-i` and `IdentitiesOnly`.
- Every setting configurable; nothing hard-codes GPUs, ports, hostnames, repos or paths.
- CI calls GYST reusable workflows, gate named `CI green`, pinned by commit with `# vX.Y.Z`; Dependabot cooldown set; dependencies pinned.
- Overhead budget: collector under 2% of one core idle, under 5% active, under 100 MB resident.
- Default layout fits 1920x1080 without scrolling.

## Review Focus

1. argv carrying secrets in forms the allowlist might miss: `--token=abc`, `-H "Authorization: Bearer x"`, `https://user:pass@host`, `KEY=val cmd`. Expect none survives into the snapshot (Task 2).
2. Control and escape characters in process names, branches, task labels (terminal escape injection). Expect stripped before any renderer (Task 2, 13, 14).
3. A source that hangs, crashes or returns garbage (hung ssh, half-written session JSON, 429 from GitHub). Expect only that source goes stale; others keep updating (Task 4).
4. Process or session vanishing mid-read, PID reuse, deleted cwd. Expect a row dropped or marked gone, never a crash or a wrong owner (Tasks 6, 8).
5. Snapshot read while being written, or collector not running. Expect renderers show last good data with age, or "collector not running", never partial JSON (Tasks 1, 13).

### Task 1: Model and snapshot store

**Files:** Create `src/fafo/model.py`, `src/fafo/store.py`; Test `tests/test_store.py`.

**Produces:**
- `@dataclass(frozen=True) class Stamped(Generic[T]): value: T; as_of: float` (Python 3.11 is the CI floor: no PEP 695 syntax)
- `class Session`: `pid:int, agent:str, session_id:str, project:Stamped[str], project_rule:str, task:str, state:str, branch:str, worktree:str, started:float, cpu:float, rss:int, name: str = "", address: str = ""` (`name` is the session name; `address` is the full session id, for manual cross-session messaging; both populated by Task 6 Step 0)
- `class Proc`: `pid, ppid, session_pid:int|None, agent, cmd:str(redacted), cpu, rss, started`
- `class LlmServer`: `models:list[LoadedModel], queue:int, inflight:list[Inflight], gpu:dict`
- `class Runner`: `name, state, repo, workflow, job, step, step_n, step_total, elapsed, load, mem, disk`
- `class SourceHealth`: `name, status:Literal["ok","stale","down","absent"], last_ok:float, error:str`
- `class Snapshot`: `version:int, taken:float, host:dict, sessions, procs, llm, runners, quota, health`
- `write_snapshot(path:Path, snap:Snapshot) -> None` (temp file in same dir, chmod 0600, `os.replace`); `read_snapshot(path:Path) -> Snapshot | None` (None if missing or invalid).

- [ ] Step 1: Tests `test_write_is_0600`, `test_roundtrip_equal`, `test_read_missing_returns_none`, `test_read_truncated_returns_none` (write half a file by hand), `test_concurrent_read_never_partial` (reader thread loops while writer writes 200 times; every read is None or a full Snapshot).
- [ ] Step 2: Run, expect FAIL (module missing).
- [ ] Step 3: Implement as signatures above; JSON with a `version` field, reject unknown major version.
- [ ] Step 4: Run, expect PASS. Commit.

### Task 4: Collector engine

### Task 18: Security review and release

**Scope note (2026-11-27, from a side-agent observation, verified in the watcher logs):** most final fix rounds merged without a fresh Copilot review on the last commit (the merge helper waited 1 to 2 minutes and printed "no review arrived"). The Daybreak pass therefore names these modules explicitly, reviewing the CURRENT main, not the PR diffs: `redact.py` (argv allowlist, mask_credentials, caps), `ghapi.py` (token handling, ETag, rate limits, exception chains), `sshro.py` (fixed op allowlist, ssh options, deadline), `procutil.py` (kill-before-reap, waitid), `config.py` (secret-key rule and the token_env/key_path allowlist, repo validator), `registry.py` and `cli.py` (value-free errors), `store.py` (modes, validation), `collector.py` (scrub, views), `sources/claude.py` (registry reads, peerToken and key files never read, PID reuse), `adapters/safo.py` (output validation, runner), `attribution.py` (git runner, URL stripping). Added after the first end-to-end run and the later PRs (2026-11-27): `jsonsafe.py` (iterative capped walks, wide-int and non-finite handling), `sources/runners.py` (fixed read-only ssh and GitHub REST), `sources/copilot.py` (Actions-run parsing), `transcript.py` (transcript tail reads, descriptor-chain open, prompt-mode masking), and the `args_mode = safe` path in `redact.py`. Process change for security-sensitive PRs from now on: a long review wait (up to 10 minutes) on the final commit, and an explicit review request if Copilot does not re-review pushes automatically.

Daybreak-tier adversarial review (three rounds max, fixtures revert-proved by a reviewer agent) of redaction, ssh helper, GitHub client and file permissions; fix findings; release through GYST `python-package-release`; verify the published artifact installs and `fafo doctor` passes on a clean machine.
